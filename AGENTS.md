# AGENTS.md

## Guardrail: público vs local

Este repo (`bicodeurubu/grafo-pm`) é o **template open source** promovido publicamente. Tudo que está versionado aqui pode ir pro GitHub público.

Trabalho real de produto (dados proprietários, decisões reais, pesquisa real) NUNCA vai na raiz deste repo. Vai em `local-vault/` — pasta com git próprio, sem remote público, gitignored pela raiz. `Product Example/` é demo intencional e fica de fora dessa regra (conteúdo fictício, feito pra ser público).

Um hook `pre-push` (`.githooks/pre-push`, ativado via `core.hooksPath`) bloqueia push se `SIGNAL.md` ou `library/01-07*.md` na raiz saírem do estado de template (`status: draft` / placeholders). Se o hook disparar, mova o conteúdo real pra `local-vault/` antes de tentar de novo.
